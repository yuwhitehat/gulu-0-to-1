## 核心问题与结果

确认核心Job，MVP范围。
### 1\. P0 用户和核心 Job

  
| 维度     | 内容                                                | 来源                            |
| ------ | ------------------------------------------------- | ----------------------------- |
| P0 用户  | 25\-30 岁 NF/NT 型人格用户，对现有 AI 聊天有轻度疲劳               | 用户调查 Q2\+Q11                  |
| 核心 Job | 解决对现有 AI 聊天"完美回答"的疲劳，通过随机性格\+盲盒\+主动聊天获得有趣的不完美对话体验 | 用户调查 Q5（64\.29% 有不满）\+ Q12 编码 |
| 产品定位   | "命中注定的灵魂盲盒"——主动找你聊天的 AI，随机性格不可定义                  | 定位/定价方案 A                     |

### 2\. MVP 做什么、不做什么

  

| 类别      | 内容                                              |
| ------- | ----------------------------------------------- |
| 做       | 飞书内 Bot、主动发消息、随机性格（NF/NT 4 种）、热搜观点碰撞、动态调整策略、长记忆 |
| 不做      | 独立 App、Jira/钉钉集成、自动修改文档、多平台集成                   |
| MVP 人格池 | NF/NT 类型（4 个角色卡片），有限池内随机抽取不可自选                  |
| 角色设计方向  | 温柔暖心型（P0）\+幽默风趣型（P0）\+理性客观型（P1）\+真诚不附和型（P1）     |

### 3\. 价值闭环



| 阶段   | 用户行为                    | 价值           |
| ---- | ----------------------- | ------------ |
| 首次接触 | 免费抽取随机性格                | 盲盒宿命感\+好奇心   |
| 首次互动 | AI 主动用热搜观点碰撞            | 不完美对话体验，打破疲劳 |
| 持续互动 | AI 动态调整碰撞/同频/欢喜冤家       | 长期趣味         |
| 付费转化 | 1 元重抽（不满意时）\+9\.9 元首月会员 | 沉没成本\+长期关系   |
| 长期留存 | 长记忆维护关系                 | "养"的行为沉没成本留人 |

### 4\. 责任边界


|责任方|责任内容|来源|
|---|---|---|
|AI|主动发消息\+热搜碰撞\+性格保持\+长记忆\+动态调整|技术可行性 Gate|
|人（初期）|审核主动消息内容\+筛选热搜话题\+处理人设崩塌\+处理投诉|容错 Gate|
|安全边界|不训练用户对话、MBTI 仅用户自己可见、敏感话题人工审核、投诉即停、未成年人保护|合规安全 Gate|

### 5\. 业务成功标准

  
|标准|阈值|来源|
|---|---|---|
|成功：会员转化率|\>5%|ROI Gate|
|成功：续费率|\>30%|ROI Gate|
|失败：人设崩塌|星野已验证痛点|容错 Gate|
|失败：碰撞引发反感|用户流失|容错 Gate|
|失败：会员转化率|\<5%|ROI Gate|
|失败：续费率|\<30%|ROI Gate|

## 定价方案

|层级|价格|作用|
|---|---|---|
|免费首次抽取|免费|获客入口，优先抽外向 NF/NT|
|重抽|1 元/次，最多 3 次|沉没成本\+命运非免费心理锚点|
|会员首月|9\.9 元/月|降低上车门槛|
|会员正常价|29 元/月|长记忆维护长期关系|
