## 本轮修订说明

| 修订点 | 本版处理 |
|---|---|
| MVP 人格池确认 | 4 张 E 型卡：ENFJ/ENFP/ENTJ/ENTP，I 型人格后续迭代（方案 C 慢热提示） |
| MBTI 字母展示 | 用户修正：展示 MBTI 字母给用户（昵称+字母+一句话简介） |
| 触发间隔按 J/P 分组 | J 人（ENFJ/ENTJ）6 小时，P 人（ENFP/ENTP）4 小时 |
| 关系递进原则 | 所有人格主动消息语气随初识/熟悉/亲密三阶段递进 |
| 对话示例修正 | ENFP 分享不加问句；ENFJ 初识只到关心提醒（且只早上发）；ENTJ 去人机感；ENTP 克制得寸进尺 |
| 重抽不排除当前人格 | 可能连续抽到同一人格，强化宿命感 |
| 第 3 次重抽隐性推断 | 不问用户，系统根据前两次行为微调加权随机 |
| 3 次上限后留存 | 三路径：加价续抽 3 元/会员转化/引导继续互动 |
| 安静时段 | 23:00-08:00 不主动，早上类提醒只发早上 |
| 投诉即停 | 永久标记不受欢迎行为，不降频再试 |

| 字段 | 内容 |
|---|---|
| Source Flow | KUF-01 首次抽取（PRD v0.7 主线第一段） |
| Source Capability | CAP-01 性格抽取（加权随机）、CAP-02 角色卡装载 |
| Source State Strategy | PS-01 抽取前状态=无人格绑定；PS-02 抽取后状态=已绑定人格+长记忆初始化 |
| Actor | 新用户 |
| 用户目标 | 抽到属于自己的随机人格，开始首次互动 |
| 前置条件 | 用户已开通飞书 Bot；尚未绑定人格；人格池有 4 张 E 型卡 |
| 触发 | 用户首次进入飞书 Bot 对话，点击"抽取我的灵魂" |
| 主路径 | ① 用户点击抽取 → ② 系统从 4 张 E 型卡加权随机抽取（优先外向 NF/NT）→ ③ 展示抽取结果（性格昵称+MBTI 字母+一句话简介）→ ④ AI 以该人格口吻发送第一条消息 → ⑤ 进入 UC-02 主动聊天循环 |
| 主路径后置状态 | 已绑定人格；长记忆初始化；首次互动时间戳记录；进入主动聊天循环 |
| 禁止行为 | 不得让用户自选人格类型；不得在抽取未完成时发送主动消息 |

## UC-02 AI 随机主动消息

| 字段 | 内容 |
|---|---|
| Source Flow | KUF-02 AI 主动发起对话（PRD v0.7 主线第二段） |
| Source Capability | CAP-03 随机主动触发、CAP-04 热搜获取与碰撞、CAP-05 性格一致性生成、CAP-06 关系阶段感知 |
| Source State Strategy | PS-03 安静时段锁；PS-04 主动消息频率控制（J/P 分组）；PS-05 敏感话题拦截；PS-06 关系熟悉度阶段标记 |
| Actor | AI 系统 |
| 用户目标 | 在用户未发起对话时，以绑定人格口吻+当前关系阶段，主动发起一条有内容的消息 |
| 前置条件 | 用户已完成 UC-01 性格抽取；当前不在安静时段（23:00-08:00）；距离上次互动超过该人格的最小间隔 |
| 触发 | 系统随机触发器（非定时、非用户操作）；触发间隔按 J/P 分组随机分布 |
| 主路径 | ① 系统随机决定触发主动消息 → ② 检查安静时段与频率规则（J/P 分组）→ ③ 查询当前关系阶段（初识/熟悉/亲密）→ ④ 随机选择内容来源（A: 热搜观点碰撞 / B: 性格驱动闲聊）→ ⑤ 以绑定人格口吻+当前关系阶段生成消息 → ⑥ 发送至飞书对话 → ⑦ 等待用户回应，进入 UC-03 |
| 主路径后置状态 | 主动消息已发送；本次触发记录入长记忆；用户回应则进入 UC-03 互动循环 |
| 禁止行为 | 不得在 23:00-08:00 发送主动消息；不得使用未审核的敏感热搜话题；不得发送与绑定人格不一致的消息；不得在初识期使用过分亲密/挑衅/霸总语气（关系未到那个阶段）；不得在晚上发送"今天降温多穿一件"类提醒（该类提醒只在早上发）；不得高频轰炸（连续 3 次未回复后必须降频） |

### UC-02 扩展路径

| 扩展 ID | 扩展名称 | 扩展来源类型 | 来源 ID | 触发 | 路径变化 | 状态变化 | 禁止行为 |
|---|---|---|---|---|---|---|---|
| UC-02-E1 | 安静时段触发 | 状态策略扩展 | PS-03 | 系统在 23:00-08:00 触发主动消息 | 延迟到次日 08:00 后补发，且早上类提醒只发早上 | 延迟发送，不暴露延迟原因 | 不得在安静时段发送 |
| UC-02-E2 | 热搜命中敏感话题 | 状态策略/边界扩展 | PS-05 | 热搜内容命中敏感话题 | 拦截，切换为性格闲聊或放弃本次触发 | 本次触发不发送热搜内容 | 不得使用未审核敏感话题 |
| UC-02-E3 | 用户连续未回复 | 状态策略扩展 | PS-04 | 用户连续 3 次未回复主动消息 | 降频至隔天 1 条 | 频率降级标记 | 不得继续高频轰炸 |

### 关系阶段与消息风格递进规则

| 人格 | 初识期（抽取后~首次互动若干轮） | 熟悉期（多轮互动后） | 亲密期（长期高频互动后） |
|---|---|---|---|
| ENFJ 主人公 | 温和关心，点到为止 | 更直接关心，带一点"我来管你" | 霸总式关心，强势但温暖 |
| ENFP 竞选者 | 分享见闻，不加追问 | 分享+好奇反问 | 分享+撒娇+强烈情绪表达 |
| ENTJ 指挥官 | 简洁有观点，客气请教 | 更直接给判断，带反问 | 高效+带个人关怀的"硬话" |
| ENTP 辩论家 | 克制试探，不过分挑衅 | 正式开始抬杠+思辨 | 极致杠精+深层信任后的柔软 |

### 触发间隔分组

| 人格分组 | 最小间隔 | 消息节奏特征 |
|---|---|---|
| J 人（ENFJ / ENTJ） | 6 小时 | 发起后畅聊很久，一次性聊透再结束 |
| P 人（ENFP / ENTP） | 4 小时 | 断断续续，一会儿一条短消息 |

## UC-03 用户互动与动态调整

| 字段 | 内容 |
|---|---|
| Source Flow | KUF-03 用户互动与 AI 动态调整（PRD v0.7 主线第三段） |
| Source Capability | CAP-06 关系阶段感知、CAP-07 用户偏好记忆与行为调整、CAP-08 碰撞模式切换 |
| Source State Strategy | PS-06 关系熟悉度阶段标记；PS-07 用户偏好画像；PS-08 互动模式标记（同频/碰撞/欢喜冤家） |
| Actor | 用户（发起互动或回应 AI 主动消息）；AI 系统（根据互动记录动态调整行为模式） |
| 用户目标 | 让 AI 的行为随用户偏好进化，形成"越聊越懂你"的长期关系 |
| 前置条件 | 用户已完成 UC-01 性格抽取；至少有 1 次互动记录；当前已绑定人格和关系阶段 |
| 触发 | 用户在飞书对话中回应 AI 的主动消息，或主动发起对话 |
| 主路径 | ① 用户发送消息（回应或主动）→ ② AI 以绑定人格口吻+当前关系阶段生成回复 → ③ 系统记录本次互动：用户同意/不同意/中性 → ④ 更新用户偏好画像和行为计数器 → ⑤ 判断是否触发模式切换阈值 → ⑥ 未达阈值则继续当前模式；达到阈值则切换模式 → ⑦ 回复用户，等待下一轮互动 |
| 主路径后置状态 | 用户偏好画像更新；互动模式可能切换；行为计数器更新；关系阶段可能推进（互动次数累计触发初识→熟悉→亲密） |
| 禁止行为 | 不得在用户投诉后继续该行为；不得在欢喜冤家模式下越过当前关系阶段的语气边界；不得一次性大幅改变 AI 性格（调整是渐进的）；不得将用户私下表达的内容用于对外展示；不得因用户不同意就完全沉默（碰撞仍在但克制） |

### UC-03 扩展路径

| 扩展 ID | 扩展名称 | 扩展来源类型 | 来源 ID | 触发 | 路径变化 | 状态变化 | 禁止行为 |
|---|---|---|---|---|---|---|---|
| UC-03-E1 | 同频模式 | 能力卡扩展 | CAP-08; PS-08 | 连续 3 次同意用户观点 | AI 更贴近用户立场，减少碰撞，多表达认同 | 互动模式切换为同频 | 不改变关系阶段 |
| UC-03-E2 | 欢喜冤家模式 | 能力卡扩展 | CAP-08; PS-08 | 连续 3 次不同意用户观点 | AI 适当碰撞、反驳，但语气不越过当前关系阶段边界 | 互动模式切换为欢喜冤家 | 不得越过关系阶段语气边界 |
| UC-03-E3 | 投诉抑制 | 状态策略/边界扩展 | PS-07; PS-08 | 用户投诉或明确拒绝某行为 | 即时停止该行为类型，标记为不受欢迎，后续不再触发 | 该行为永久标记不受欢迎 | 不得在投诉后继续该行为；不得降频再试（永久标记） |

### 模式切换规则

| 模式 | 触发条件 | AI 行为变化 | 与关系阶段的联动 |
|---|---|---|---|
| 同频模式 | 连续 3 次同意用户观点 | 更贴近用户立场，减少主动碰撞，多表达认同 | 不改变关系阶段，互动次数正常累计推进 |
| 欢喜冤家模式 | 连续 3 次不同意用户观点 | 适当碰撞、反驳，但语气不越过当前关系阶段边界 | 同上 |
| 投诉抑制 | 用户投诉或明确拒绝某行为 | 即时停止该行为类型，标记为不受欢迎，后续不再触发 | 不改变关系阶段，但可能影响关系推进速度 |

### 关系阶段推进规则

| 阶段 | 进入条件 | AI 语气边界 |
|---|---|---|
| 初识期 | 默认（抽取后） | 温和克制，不挑衅/不霸总/不亲密 |
| 熟悉期 | 累计互动 ≥ 10 轮 | 可展现人格典型特质（ENTP 开始抬杠、ENFJ 带点管束感） |
| 亲密期 | 累计互动 ≥ 30 轮 + 用户未投诉 | 可使用人格极致风格（霸总/撒娇/极致杠精/深层柔软） |

```text
AI: 诶，我跟你说个事——咱们这样聊的日子好像快到期了。你要是想继续让我这么找你聊、记得你说过的话……续一下嘛？现在首月才 9.9。
```
*（性格化引导，不生硬弹窗）*

#### 会员激活成功（ENTJ 指挥官）

```text
AI: 好了，续上了。以后我会继续来找你——你说过的事我也都记着。对了，还送了你一次重新抽的机会，要用随时说。
```
*（简洁确认权益，符合 ENTJ 风格）*

#### 会员到期降级（ENTP 辩论家）

```text
AI: 你看，又找我聊了吧——但我现在不太记得你上次说的了。不是我不想记，是你的会员到期了。想让我继续记着你的话？续一下呗。
```
*（用性格化方式表达落差，引导重新开通）*

#### 取消续费通知（ENFJ 主人公）

```text
System: 你的会员将在 3 天后到期。到期后记忆不会删除，但会暂时沉睡——随时回来，它还在等你。
```
*（提前通知，不删除记忆，留回归入口）*

|---|---|---|
| 主对象记录 | UC-01 首次抽取性格 | 用户抽取并绑定人格，系统记录绑定关系和长记忆初始化 |
| 历史对象/上下文复用 | UC-04 长记忆跨会话 | AI 跨会话检索用户历史记忆并注入当前对话上下文 |
| 补一句/修正 | UC-04 EXT-02 用户指出记错 | AI 承认并纠正，更新记忆条目 |

| 按需搜索/外部信息查询 | UC-02 热搜获取与碰撞 | AI 主动消息时抓取热搜内容生成碰撞话题 |
| 最小追问 | UC-02 对话示例中 ENFP/ENTJ 的轻量反问 | 分享后不加问卷式追问，只给一个轻量反问或不问 |

| 受限建议边界 | UC-02 EXT-02 敏感话题拦截 + UC-03 投诉即停 | 热搜命中敏感话题拦截切换；投诉即停永久标记 |
| 非评判和压力保护 | UC-03 投诉抑制 + UC-04 用户指出记错 | 投诉后不争辩、记忆记错后不过度道歉 |
| 数据控制和调用阻断 | UC-04 记忆冻结 + UC-06 会员降级 | 免费用户记忆冻结不删除；会员到期降级但对话不断 |

| 状态点 | 来源 UC / 扩展 | M2 需要表达清楚的用户可见状态 |
