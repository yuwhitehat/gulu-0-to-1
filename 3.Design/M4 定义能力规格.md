## CAP-01 性格抽取（加权随机）

| 项 | 规格 |
|---|---|
| 能力 ID | CAP-01 |
| 能力名称 | 性格抽取（加权随机） |
| 支撑 Use Case | UC-01 首次抽取、UC-05 付费重抽 |
| 职责 | 从人格池中加权随机抽取一个 E 型人格卡，首次免费、重抽付费；第 3 次重抽加入隐性推断微调权重；不排除当前人格（可能连续命中同一人格） |
| 输入 | 抽取请求（首次/重抽）、当前重抽计数、用户行为信号（第 3 次隐性推断用） |
| 输出 | 抽取结果（MBTI 字母+昵称+简介） |
| 调用条件 | 用户点击抽取/重抽确认支付后；首次抽取无前置条件，重抽需付费校验通过 |
| 知识/记忆 | 人格池（4 张 E 型卡定义）；加权权重配置（优先外向 NF/NT） |
| 工具/权限 | 无外部工具调用；权重配置只读 |
| 失败、停止与人工 Gate | 抽取异常→重试一次（UC-01 EXT-02）；第 3 次隐性推断不暴露给用户；连续命中提示由系统判定触发 |
| 不可接受行为 | 不得让用户自选人格；不得在未付费时执行重抽；不得暴露隐性推断机制；不得排除当前人格 |
| 可观察证据 | 抽取结果卡片（昵称+MBTI+简介）；连续命中系统提示语 |
| 明确不负责 | 不负责角色卡内容生成（CAP-02 负责）；不负责付费校验（CAP-10 负责） |

## CAP-02 角色卡装载

| 项 | 规格 |
|---|---|
| 能力 ID | CAP-02 |
| 能力名称 | 角色卡装载 |
| 支撑 Use Case | UC-01 首次抽取、UC-05 付费重抽 |
| 职责 | 抽取结果确定后，装载对应角色卡（口吻、句式、口语化标记、不完美感表现、关系阶段语气边界），初始化长记忆和关系阶段 |
| 输入 | 抽取结果（MBTI 字母） |
| 输出 | 已绑定人格+长记忆初始化+关系阶段=初识期 |
| 调用条件 | CAP-01 抽取成功后自动调用 |
| 知识/记忆 | 角色卡定义（ENFJ/ENFP/ENTJ/ENTP 各自的口吻、句式、口语化标记、关系阶段语气边界） |
| 工具/权限 | 无外部工具调用 |
| 失败、停止与人工 Gate | 角色卡装载失败→抽取重试（UC-01 EXT-02） |
| 不可接受行为 | 不得在装载未完成时发送 AI 消息；不得保留旧人格记忆（重抽时必须清除） |
| 可观察证据 | AI 首条消息以正确人格口吻发出 |
| 明确不负责 | 不负责抽取逻辑（CAP-01 负责）；不负责记忆内容（CAP-09 负责） |

## CAP-03 随机主动触发

| 项 | 规格 |
|---|---|
| 能力 ID | CAP-03 |
| 能力名称 | 随机主动触发 |
| 支撑 Use Case | UC-02 AI 主动消息、UC-06 会员激活 |
| 职责 | 在用户未发起对话时，按 J/P 分组随机间隔触发主动消息；检查安静时段（23:00-08:00）；检查连续未回复次数，3 次后降频至隔天 1 条 |
| 输入 | 当前时间、绑定人格（J/P 分组）、上次互动时间戳、连续未回复计数、会员状态 |
| 输出 | 触发信号（触发/延迟到次日/降频/跳过） |
| 调用条件 | 系统后台随机触发器运行；用户无感知 |
| 知识/记忆 | J/P 间隔配置（J=6h，P=4h）；安静时段规则；降频规则 |
| 工具/权限 | 无外部工具调用；时间查询只读 |
| 失败、停止与人工 Gate | 安静时段触发→延迟到次日 08:00 后补发；连续 3 次未回复→降频；免费用户试用期满→降频/冻结（CAP-09 联动） |
| 不可接受行为 | 不得在 23:00-08:00 发送；不得在连续 3 次未回复后继续高频发送；不得对免费试用期满用户维持正常频率 |
| 可观察证据 | AI 主动消息出现在飞书对话流中（用户无感触发机制） |
| 明确不负责 | 不负责消息内容生成（CAP-05 负责）；不负责热搜获取（CAP-04 负责） |

## CAP-04 热搜获取与碰撞

| 项 | 规格 |
|---|---|
| 能力 ID | CAP-04 |
| 能力名称 | 热搜获取与碰撞 |
| 支撑 Use Case | UC-02 AI 主动消息 |
| 职责 | 获取平台热搜话题（优先小红书）；对热搜内容做敏感话题过滤；将热搜话题与绑定人格口吻碰撞生成话题素材 |
| 输入 | 触发信号（来自 CAP-03） |
| 输出 | 热搜话题素材（通过/拦截） |
| 调用条件 | CAP-03 触发后，随机选择内容来源（热搜碰撞或性格闲聊） |
| 知识/记忆 | 热搜平台配置（小红书优先）；敏感话题关键词库 |
| 工具/权限 | 热搜爬取工具（外部 API/爬虫）；敏感话题过滤（人工审核 Gate：初核后人工确认） |
| 失败、停止与人工 Gate | 热搜获取失败→切换为性格闲聊（CAP-05 兜底）；热搜命中敏感话题→拦截，切换为性格闲聊或放弃本次触发；敏感话题需人工审核确认 |
| 不可接受行为 | 不得使用未审核的敏感热搜话题；不得编造热搜来源；不得抓取隐私数据 |
| 可观察证据 | AI 主动消息中包含热搜话题内容（用户看到具体话题） |
| 明确不负责 | 不负责触发时机（CAP-03 负责）；不负责最终消息生成（CAP-05 负责）；不负责敏感话题审核结果（人工 Gate 负责） |

## CAP-05 性格一致性生成

| 项 | 规格 |
|---|---|
| 能力 ID | CAP-05 |
| 能力名称 | 性格一致性生成 |
| 支撑 Use Case | UC-01 首条消息、UC-02 主动消息、UC-03 互动回复、UC-04 记忆引用回复 |
| 职责 | 以绑定人格口吻+当前关系阶段+当前互动模式生成 AI 回复；保证性格一致性（口吻、句式、口语化标记、不完美感表现不越过关系阶段边界） |
| 输入 | 绑定人格、当前关系阶段（初识/熟悉/亲密）、当前互动模式（同频/碰撞/投诉抑制）、热搜话题素材（如有）、历史记忆（如有，来自 CAP-09） |
| 输出 | AI 回复消息文本 |
| 调用条件 | 首次抽取后首条消息；CAP-03 触发后主动消息；用户互动后回复 |
| 知识/记忆 | 角色卡口吻定义（CAP-02 提供）；关系阶段语气边界；工种涌现规则（初识模糊→熟悉锁定） |
| 工具/权限 | LLM 生成工具（调用公司接入的 LLM） |
| 失败、停止与人工 Gate | 生成失败第 1 次→自动重试 1 次（用户无感）；重试仍失败→AI 以性格化方式承认故障（"我脑子突然卡住了，等会儿再找你"），不暴露技术细节也不糊弄用户；生成内容偏离人格→人工审核 Gate 介入，人设崩塌需人工介入暂停自动生成 |
| 不可接受行为 | 不得发送与绑定人格不一致的消息；不得在初识期使用过分亲密/挑衅/霸总语气；不得当百科背条目式输出；不得当客服用"亲""请问有什么可以帮您"；不得在生成失败后用正常兜底回复糊弄用户 |
| 可观察证据 | AI 回复消息口吻一致、关系阶段语气适配、不越过边界；生成失败时 AI 性格化承认"状态不对" |
| 明确不负责 | 不负责触发时机（CAP-03 负责）；不负责热搜获取（CAP-04 负责）；不负责记忆存储（CAP-09 负责） |

### CAP-05 生成失败处理

| 子状态 | 处理 | 可见表达 |
|---|---|---|
| 生成失败-第 1 次 | 自动重试 1 次 | 用户无感 |
| 重试仍失败 | AI 以性格化方式承认故障，不假装正常 | "我脑子突然卡住了……等会儿再找你聊，我先缓缓" |
| 生成内容偏离人格 | 人工审核 Gate 介入 | 人设崩塌需人工介入，暂停该人格自动生成 |

## CAP-06 关系阶段感知

| 项 | 规格 |
|---|---|
| 能力 ID | CAP-06 |
| 能力名称 | 关系阶段感知 |
| 支撑 Use Case | UC-02 主动消息、UC-03 互动、UC-04 长记忆 |
| 职责 | 维护和感知用户与 AI 的关系阶段（初识期/熟悉期/亲密期），根据互动计数推进阶段；为 CAP-05 提供当前阶段语气边界约束；为 CAP-07 提供阶段上下文 |
| 输入 | 互动计数（来自 CAP-07）、用户投诉状态 |
| 输出 | 当前关系阶段标记 |
| 调用条件 | 每次互动后更新；CAP-05 生成回复时读取 |
| 知识/记忆 | 阶段推进阈值（10 轮→熟悉、30 轮+未投诉→亲密）；各阶段语气边界定义 |
| 工具/权限 | 无外部工具调用；阶段标记读写 |
| 失败、停止与人工 Gate | 阶段推进失败→保持当前阶段不降级；用户投诉→不改变阶段但可能影响推进速度 |
| 不可接受行为 | 不得在用户投诉后推进关系阶段；不得一次性跳过阶段（必须渐进）；不得在初识期使用亲密期语气 |
| 可观察证据 | AI 语气随阶段自然变化（用户无感阶段名称，只感受到行为变化） |
| 明确不负责 | 不负责偏好画像（CAP-07 负责）；不负责模式切换（CAP-08 负责） |

## CAP-07 用户偏好记忆与行为调整

| 项 | 规格 |
|---|---|
| 能力 ID | CAP-07 |
| 能力名称 | 用户偏好记忆与行为调整 |
| 支撑 Use Case | UC-03 互动、UC-04 长记忆 |
| 职责 | 每次互动后记录用户同意/不同意/投诉信号，更新用户偏好画像和行为计数器；触发模式切换阈值判断（→CAP-08）；投诉行为永久标记不受欢迎 |
| 输入 | 用户互动文本（分类为同意/不同意/投诉/中性） |
| 输出 | 更新后的偏好画像、行为计数器、投诉标记 |
| 调用条件 | 每次用户互动后 |
| 知识/记忆 | 用户偏好画像（喜欢/不喜欢的行为、话题倾向）；投诉标记（永久不衰减） |
| 工具/权限 | 无外部工具调用；偏好画像读写 |
| 失败、停止与人工 Gate | 偏好更新失败→保持当前画像不变；投诉标记写入失败→不执行该行为但需人工确认标记 |
| 不可接受行为 | 不得在投诉后继续该行为；不得降频后再试投诉标记的行为（永久标记）；不得将用户私下表达的内容对外展示 |
| 可观察证据 | AI 行为随偏好调整（同频/碰撞/投诉抑制后收敛）；投诉后 AI 即时收敛 |
| 明确不负责 | 不负责关系阶段（CAP-06 负责）；不负责模式切换执行（CAP-08 负责）；不负责长记忆存储（CAP-09 负责） |

## CAP-08 碰撞模式切换

| 项 | 规格 |
|---|---|
| 能力 ID | CAP-08 |
| 能力名称 | 碰撞模式切换 |
| 支撑 Use Case | UC-03 互动 |
| 职责 | 根据 CAP-07 的行为计数器判断是否触发模式切换：连续 3 次同意→同频模式；连续 3 次不同意→欢喜冤家模式；用户投诉→投诉抑制模式。切换后为 CAP-05 提供当前模式约束 |
| 输入 | 行为计数器（同意计数/不同意计数/投诉标记，来自 CAP-07） |
| 输出 | 当前互动模式（同频/碰撞/欢喜冤家/投诉抑制） |
| 调用条件 | 每次互动后判断阈值 |
| 知识/记忆 | 模式切换阈值（3 次同意/3 次不同意）；投诉抑制规则（永久标记） |
| 工具/权限 | 无外部工具调用；模式标记读写 |
| 失败、停止与人工 Gate | 模式切换失败→保持当前模式不变 |
| 不可接受行为 | 不得在欢喜冤家模式下越过当前关系阶段语气边界；不得一次性大幅改变 AI 性格（调整渐进）；不得因用户不同意就完全沉默 |
| 可观察证据 | AI 回复风格随模式变化（同频温和/碰撞活泼/投诉后克制） |
| 明确不负责 | 不负责偏好记录（CAP-07 负责）；不负责关系阶段（CAP-06 负责） |

## CAP-09 长期记忆存储与检索

| 项 | 规格 |
|---|---|
| 能力 ID | CAP-09 |
| 能力名称 | 长期记忆存储与检索 |
| 支撑 Use Case | UC-04 长记忆跨会话、UC-06 会员激活 |
| 职责 | 存储和检索用户长期记忆（5 类：偏好画像/关键事件/关系阶段/行为模式/日常闲聊）；按衰减策略管理记忆权重；会员冻结/恢复记忆调用 |
| 输入 | 互动记录（写入）、记忆检索请求（读取） |
| 输出 | 记忆检索结果（相关条目）或空结果 |
| 调用条件 | 每次互动后写入；用户聊旧话题或 AI 引用历史时检索；关系阶段推进时读取计数 |
| 知识/记忆 | 5 类记忆内容（偏好画像/关键事件/关系阶段/行为模式/日常闲聊）；衰减策略（日常闲聊 7 天衰减，其余不衰减或永久） |
| 工具/权限 | 记忆存储工具（向量数据库/文档存储）；不训练用户对话数据 |
| 失败、停止与人工 Gate | 检索失败→降级为无历史上下文回复，AI 性格化过渡（"脑子没转过来"），不暴露技术故障；用户指出记错→承认纠正更新条目；免费用户记忆冻结→不删除只冻结调用 |
| 不可接受行为 | 不得将用户对话数据用于模型训练；不得对外展示用户记忆内容；不得在检索失败时暴露技术故障；不得在用户指出记错后否认争辩；不得对免费用户完全切断对话；不得删除冻结的记忆（只冻结不删除） |
| 可观察证据 | AI 自然引用历史（"你上次说……"）；用户感受到"它记得我"；免费用户感受到"它不太记得了"的落差 |
| 明确不负责 | 不负责偏好分类（CAP-07 负责）；不负责关系阶段判断（CAP-06 负责） |

## CAP-10 重抽计数器与付费校验

| 项 | 规格 |
|---|---|
| 能力 ID | CAP-10 |
| 能力名称 | 重抽计数器与付费校验 |
| 支撑 Use Case | UC-05 付费重抽、UC-06 会员激活 |
| 职责 | 维护重抽计数器（0~3 次+加价续抽模式）；校验付费状态（1 元/3 元）；校验会员状态（首月 9.9/正价 29）；3 次上限后触发留存路径判断 |
| 输入 | 重抽请求、付费确认信号、会员开通/到期信号 |
| 输出 | 重抽许可/拒绝、重抽计数更新、会员状态更新、3 次上限路径触发 |
| 调用条件 | 用户点击重抽→校验计数→弹窗确认→支付校验通过后许可 CAP-01 执行抽取 |
| 知识/记忆 | 重抽定价阶梯（1 元×3 次→3 元/次不限）；会员定价（9.9 首月→29 正价）；会员权益配置 |
| 工具/权限 | 支付系统工具（外部支付接口）；会员状态存储 |
| 失败、停止与人工 Gate | 支付失败→不执行重抽，保留当前人格，计数器不变；支付取消→同上；3 次上限→不硬截断，触发三路径留存（A 加价续抽/B 会员转化/C 引导互动） |
| 不可接受行为 | 不得免费重抽（首次免费后必须付费）；不得在用户未确认支付前执行抽取；不得超 3 次后直接关闭功能不留存路径；不得在用户未确认前自动扣费开通会员；不得在会员到期后删除记忆（联动 CAP-09 只冻结） |
| 可观察证据 | 付费弹窗（价格+计数+覆盖记忆提示）；3 次上限后"还是不满意"按钮→三路径卡；会员开通成功确认 |
| 明确不负责 | 不负责抽取逻辑（CAP-01 负责）；不负责记忆存储（CAP-09 负责）；不负责角色卡装载（CAP-02 负责） |
