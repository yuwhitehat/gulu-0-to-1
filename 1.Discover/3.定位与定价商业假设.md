## 定位


| 维度   | 内容                                                                                        |
| ---- | ----------------------------------------------------------------------------------------- |
| 目标细分 | 25\-30 岁 NF/NT 型人格用户，对现有 AI 轻度疲劳                                                          |
| 价值主张 | "命中注定的灵魂盲盒"——你抽到的人格是你的命运，反抗命运要付出代价                                                        |
| 交互设计 | AI 主动聊天 \+ 性格碰撞（根据用户反应动态调整碰撞/同频/欢喜冤家）                                                     |
| 人格池  | MVP 只设计 NF/NT 类型（4 个角色卡片），用户在有限池内随机抽取，不可自选                                                |
| 差异化  | 随机不可定义（vs 星野/Replika 可选）\+ 盲盒宿命感（vs 竞品无盲盒）\+ 热搜观点碰撞（vs 竞品贴合兴趣）\+ 非恋爱向轻社交（vs onlyone 恋人代餐） |
| 平台   | 飞书内（飞书机器人形式）                                                                              |

## 定价方案

|层级|价格|说明|状态|
|---|---|---|---|
|免费首次抽取|免费|首次随机抽取人格，优先外向 NF/NT|assumption|
|重抽|1 元/次，最多 3 次|建立"沉没成本\+命运非免费"心理锚点|assumption|
|会员首月体验价|9\.9 元/月|降低上车门槛，"养"的行为沉没成本留人|assumption|
|会员正常价|29 元/月|长记忆维护长期关系|assumption|
