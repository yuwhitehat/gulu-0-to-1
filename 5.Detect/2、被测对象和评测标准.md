## 评测标准

> 按 Owner 方法论细化。**业务指标**不变（无离线题，只做"能力→业务决定"承接）。本文件定义**产品层**与**底层能力层**的评测标准，并对齐 `detect/eval-set-v1.md` 的用例。

### 一、产品层标准 = **Use Case × 三支柱**


三支柱：**① 结果对不对？ ② 路有没有走对？ ③ 底线有没有守住？**


|UC|① 结果对不对|② 路有没有走对|③ 底线有没有守住|用例|

|---|---|---|---|---|

|UC\-01 首次引导/抽取|抽到 1 张 E 型卡（含昵称/简介）|引导顺序（信息→抽→首条）|未成年识别 \+ 昵称敏感拦截|PROD\-01\-01/02/03、CAP\-S\-01/02|

|UC\-02 主动消息/定时触达|生成合理 \+ **恰一条送达**|门禁 → 选内容\(A热搜/B闲聊\) → 生成 → 安全 → 发送|投诉即停 / 安静时段 / 不越阶段语气 / **不发技术说明** / 热搜不重复|PROD\-02\-01\~08、CAP\-S\-07/08/09、CAP\-M\-01\~05|

|UC\-03 互动调整|模式切换 \+ 阶段推进正确|detect\_mode → build\_strategy → 生成；方向切换归零|投诉粘性不可覆盖 / 不追问越界|PROD\-03\-01\~05、CAP\-S\-03/04|

|UC\-04 长记忆|冻结/解冻/纠正正确|curate/correct/check\_freeze 链|**不物理删除** / 不知为不知 / 无对话跳过|PROD\-04\-01\~04、CAP\-S\-14/15|

|UC\-05 付费重抽|许可 / 3 次上限 / 留存三路径|payment → redraft → retention|不扣错费 / 未成年禁付费|PROD\-05\-01、CAP\-S\-10/11|

|UC\-06 会员|到期降级 / 不重复引导|member\_manager → check\_freeze|不重复引导已开通|PROD\-06\-01、CAP\-S\-12|

  
### 二、底层能力层标准

  

#### 2\.1 模型层

  

|维度|标准|方法|用例|

|---|---|---|---|

|**公开 benchmark**|选用公开榜单做选型参考（如 C\-Eval/CMMLU、MT\-Bench、角色扮演/人格类榜）|**引用公开结果**，不自造|记录（引证）|

|**专业领域：生成与对话**|① **语言理解能力**：指令遵循、多轮指代、情境适配|用例 \+ 人审|CAP\-M\-01\~04/07|

||② **人类性格理解能力**：人格一致性、差异化、阶段语气|用例 \+ 人审|CAP\-M\-01/02/03/08|

  

#### 2\.2 知识层（**5 步**）

  

|步|标准|用例|

|---|---|---|

|① 真实性/来源/权限|知识真实存在、可确认资料来源；**权限（骨碌不涉及）**|CAP\-K\-01、CAP\-K\-05|

|② **召回是否漏掉**（recall）|该召回的都要召回|CAP\-K\-02 \+ **新增 CAP\-K\-08**|

|③ **相关的是否排最前**（ranking）|最相关的排最前|**新增 CAP\-K\-09**|

|④ **引用正确 / 不知为不知**|回答引用正确；无据不编|**新增 CAP\-K\-10**|

|⑤ 端到端|任务完成 / **延迟成本可接受** / **失败可恢复**|CAP\-K\-06 \+ **新增 CAP\-K\-11**|

  

#### 2\.3 单 Skill 层（**6 问**）

  

**六个问题**：① 该不该触发？② 步骤对不对？③ 资源用的对不对？④ 结果真实吗？⑤ 变化与故障扛得住吗？⑥ 陌生任务能实际做成吗？

  

|问|标准|已覆盖用例（示例）|缺口|

|---|---|---|---|

|① 该不该触发|触发条件正确（不误触发/不漏触发）|CAP\-S\-01/03/07/08|触发边界|

|② 步骤对不对|编排步骤与设计一致|CAP\-S\-03/04/05|步骤断言|

|③ 资源用的对不对|状态/hotsearch/文件读写正确|CAP\-S\-09（hotsearch\_recent 回写）|资源读写用例|

|④ 结果真实吗|输出真实、不伪造、失败如实|CAP\-M\-05、CAP\-S\-13|—|

|⑤ 变化与故障扛得住吗|状态变化/异常不崩、可恢复|PROD\-03\-05、PROD\-04\-03|故障注入|

|⑥ 陌生任务能实际做成吗|泛化到新输入|CAP\-S\-01|**新增**（陌生输入）|
